# Prompt 05: Dashboard Base Layout and Navigation

## Objective
Design the user interface structural layout for the dashboard in `app/dashboard/page.tsx`.

## Requirements
- Create a two-column responsive desktop layout (sidebar navigation and main viewport area).
- Implement responsive tab navigation switching between:
  - **Preview Builder**: Interactive scraper console.
  - **History & Collections**: Preview gallery and organization.
  - **API Dashboard**: Developer metrics and credentials portal.
- Apply high-contrast glassmorphic panels, dark backgrounds, and subtle borders.
