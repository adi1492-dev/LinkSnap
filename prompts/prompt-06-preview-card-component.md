# Prompt 06: Preview Card Component

## Objective
Create the `PreviewCard` UI component in `components/preview-card.tsx` to beautifully render links.

## Requirements
- Support vertical card design featuring high-resolution cover image, domain favicon, title, and site description.
- Implement CSS animations and smooth transitions on hover (e.g. slight transform translate and shadow glow).
- Ensure responsiveness across mobile screens and desktop frames.
- Render fallback images or text placeholder styles if fields are missing.
